# غاز أرون (Gaz Aron)

متجر لبيع واستبدال أسطوانات غاز الطبخ المنزلي.

## الحالة
المشروع جاهز للتدشين.

## الميزات المنفذة
- طلب أونلاين + تتبع الطلبات
- حسابات مستخدمين (تسجيل دخول)
- لوحة تحكم (منتجات، طلبات، مدن)
- نقاط ولاء
- تواصل معنا
- شروط وأحكام
- إشعارات (خدمة جاهزة)
- ويب + أندرويد + آيفون

## التشغيل
```bash
npm install
npx expo start
```

## الاختبارات
```bash
npm test
```

## التدشين على هوستنجر
1. أنشئ مشروعاً على Supabase ونفذ `supabase/schema.sql` ثم `supabase/seed.sql`
2. ضع المفاتيح في ملف `.env`
3. أنشئ بناء الويب: `npx expo export --platform web`
4. ارفع محتوى مجلد `dist` على هوستنجر
