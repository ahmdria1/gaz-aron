# غاز أرون (Gaz Aron)

متجر لبيع واستبدال أسطوانات غاز الطبخ المنزلي.

## الميزات
- طلب أونلاين + تتبع الطلب
- حسابات مستخدمين (تفعيل بالإيميل)
- دفع إلكتروني أو عند التسليم
- إشعارات
- نقاط ولاء
- تقييم الطلبات
- لوحة تحكم (مدن، منتجات، طلبات، مستخدمين)
- تواصل معنا + شروط وأحكام

## المنصات
- ويب سايت
- أندرويد
- آيفون

## التشغيل
```bash
npm install
npx expo start
```
