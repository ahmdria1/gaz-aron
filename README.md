# غاز أرون (Gaz Aron)

متجر لبيع واستبدال أسطوانات غاز الطبخ المنزلي.

## الميزات
- طلب أونلاين
- تتبع الطلب
- حسابات مستخدمين (تفعيل بالإيميل)
- دفع إلكتروني أو عند التسليم
- إشعارات
- نقاط ولاء
- تقييم الطلبات
- لوحة تحكم لإدارة المدن والأسعار

## المنصات
- ويب سايت
- أندرويد
- آيفون

اللغة الافتراضية: العربية
